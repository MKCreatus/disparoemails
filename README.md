# Disparo de E-mails

Aplicativo de gerenciamento de campanhas de e-mail integrado ao CRM Bitrix24, desenvolvido com Alaio VibeCode.

## Funcionalidades planejadas
- Gestão de campanhas
- Integração com contatos e empresas do Bitrix24
- Segmentação de destinatários
- Agendamento de campanhas
- Integração com provedor de envio em massa
- Controle de filas e limites autorizados
- Relatórios de entregabilidade
- Descadastro e gestão de consentimento

## Status
Projeto em desenvolvimento. Nenhum envio real habilitado.
